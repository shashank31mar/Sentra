## The 9 tenets (use verbatim as the doc's Tenets section)

1. **Enforcement is local; the control plane is never on the action path** (master tenet 1) — the distilled model + D-nodes run in the PDP on the action path; the offline retrain loop is control-plane / cold-path, NEVER on `/v1/validate`.
2. **Fail secure, never fail open** (master tenet 2) — a dropped/errored D-layer abstains to the deterministic floor or re-raises to a fail-secure DENY; a stub replacement never opens a fail-open hole; abstain is never treated as "clean".
3. **Deny-by-default, explainable** (master tenet 3) — every D-node names its deciding `Source`; its `Signal` is captured into WS-D's decision trail; a new `Source` must be registered so the trail joins on it.
4. **Defense in depth** (master tenet 4) — D1–D7 are independent layers, each ABSTAINs on error/disable and is never a sole defense; evading one is caught by another.
5. **Latency scales with risk, not volume** (master tenet 5) — the distilled model classifies the common case cheaply so the heavy tier + D-nodes (tier-1) run only on tier-0 survivors / edge cases; no summed latency (parallel-gather + chains).
6. **The data boundary is the customer's to set** (master tenet 6) — D-nodes read the post-NER-barrier redacted view; no raw PHI retained by the reclassify loop (redacted records only).
7. **Honest staging** (master tenet 8) — ship deterministic floors first; each D-layer + the ML tiers graduate shadow->enforce via `metadata['enforce']`, NOT simultaneous ship; sub-PRD P1/P2 marks are honored with per-layer sequencing.
8. **Tie-breaker A — grow the contract additively:** new `Source.*` constants, D-nodes, and phase handlers are additive; no re-cut of the `phase` field, the `_CONTENT_FIELD` map, the `ValidatorNode` vocabulary, or the existing `DEFAULT_PRIORITIES` / tie-break.
9. **Tie-breaker B — record what ran; force nothing extra:** D-nodes register into the DAG so WS-D records what actually executed; producing the trail must not force layers to run that risk didn't warrant (`evaluate_all` is the opt-in high-assurance mode, not the default).
